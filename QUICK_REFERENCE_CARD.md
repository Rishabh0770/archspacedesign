## 🔧 Easy Customization

### Change Images
```html
<!-- Desktop -->
<div class="hero-slide hero-slide-desktop"
  style="background-image: url('YOUR-IMAGE')"></div>

<!-- Mobile -->
<div class="hero-slide hero-slide-mobile"
  style="background-image: url('YOUR-IMAGE')"></div>
```

### Change Text
```html
<h1>Your Title<span>Your Tagline</span></h1>
<p class="hero-subtitle">Your subtitle</p>
```

